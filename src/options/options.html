答题引擎

完全免费：不填任何 Key，直接用你在浏览器里已经登录的 chat.deepseek.com 算答案。开启后会在后台自动开一个 DeepSeek 标签页 （不会抢你的焦点，你可以继续用电脑干别的），每道题用它开一个新会话，把题目打进去、 等它答完、把答案抠回来。
注意：那个标签页不要关，也不要在扩展里退登录；偶尔会弹人机验证，需要你手动点一下。 每题约 8~20 秒，比 API 慢。自动化操作网页版可能违反其服务条款，有封号风险，请自行判断。 另外本机 Ollama 是完全离线、没有条款风险的免费替代，可以对比着用。

这是唯一能让「下载即用、朋友零配置」成立的办法。 原版之所以装上就能用，是因为题目发到 daxuesoutijiang.com 由他们的服务器算答案 —— 这部分不是代码，掏不出来。
但你可以自己扮演同样的角色：把 server/answer-relay.mjs 和你的一个 API Key 放到任意一台能跑的机器上（自己的电脑、服务器、云函数都行）， 然后把地址填到这里。朋友那边不需要任何 Key、不需要装任何东西， 直接装扩展就能用，算力在你这边。
把地址写进 src/background/index.js 顶部的 DEFAULT_RELAY_URL 常量、再把 DEFAULT_ANSWER_SOURCE 改成 "relay"，打包发出去就是完全零配置。

题目若含图片会自动以视觉消息（image_url）发送，此时需要视觉模型；纯文字题任何 chat 模型都可以，纯文字模型答含图题会漏掉题干里的图。
本机 Ollama（完全免费，推荐）：装好 Ollama 后执行 ollama pull qwen2.5:7b（纯文字，约 4.7 GB）或 ollama pull qwen2.5vl:7b（支持看图，约 6 GB）， 地址填 http://127.0.0.1:11434/v1，Key 随便填。 第一次出题会等十几秒（模型加载进显存），之后就快了。

本地题库（零成本复用）

同一道题只解一次，之后再遇到直接秒答、零花费。题目身份按 「questionId → 题干+选项哈希 → 图片哈希」判定；带 questionId 的题目最可靠。
未命中时仍会请求引擎，并自动把新答案写进题库（不受上面开关影响）， 所以即使暂时关掉它，题库也会持续积累。超星的测验题复用率很高， 这一层的省钱效果通常比换引擎还大。
